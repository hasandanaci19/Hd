# İnteraktif Gezi Haritası 🗺️

Yapay zekâ destekli, PHP tabanlı interaktif gezi planlama uygulaması.

## Özellikler

✈️ **İnteraktif Gezi Haritası** - Google Maps entegrasyonu ile harita görüntüleme
🤖 **Yapay Zekâ Rota Önerici** - OpenAI API ile akıllı rota önerileri
🌦️ **Hava Durumu Entegrasyonu** - OpenWeatherMap API
⛽ **Yakıt Maliyeti Hesaplayıcısı** - Mesafe ve yakıt türüne göre hesaplama
🏕️ **Kamp Alanı Puanlama Sistemi** - Kullanıcı yorumları ve derecelendirme
📸 **Fotoğraf Yükleme** - Gezi fotoğraflarını paylaş
👨‍👩‍👧‍👦 **Çocuklu Aile Uygunluğu** - Aile dostu yerler puanlandırması
🚐 **Karavan Uygunluğu** - Karavan ile uyumlu rotalar

## Teknoloji Stack

- **Backend**: PHP 7.4+
- **Database**: MySQL 5.7+
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **APIs**: Google Maps, OpenAI, OpenWeatherMap
- **Server**: Apache 2.4+

## Kurulum

1. Repository'yi klonlayın
2. `config/database.php` dosyasını düzenleyin
3. `db/schema.sql` dosyasını MySQL'e aktarın
4. API anahtarlarını `.env` dosyasına ekleyin
5. Web sunucusunda çalıştırın
